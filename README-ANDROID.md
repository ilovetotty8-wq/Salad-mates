# Salad Mate Chef — Android APK

This project is packaged as an Android app using Capacitor.

## Build the APK without Android Studio

1. Upload/push this project to a GitHub repository.
2. Open **Actions**.
3. Select **Build Salad Mate Chef APK**.
4. Press **Run workflow** (or push to `main`).
5. When it finishes, open the workflow run and download the **Salad-Mate-Chef-APK** artifact.
6. Extract the artifact and install `app-debug.apk` on your Android phone.

The package ID is `com.saladmate.chef` and the app name is **Salad Mate Chef**.
