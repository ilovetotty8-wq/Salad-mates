# Tracker Mate

Starter Flutter app for food-product production traceability.

## Included
- Create reusable product templates
- Add ingredients to each product
- Start a production run from a saved product
- Automatically record the production date/time
- Enter how many times the recipe was made
- Enter total quantity produced
- Enter boxes produced
- Enter a different lot code for every ingredient on every production run
- Save production history locally
- Search history by product, date/time, batch ID, or lot code

## Run
1. Install Flutter.
2. Extract this folder.
3. Run `flutter pub get`.
4. Run `flutter run`.

This is the first working foundation. Cloud sync, employee accounts, barcode scanning, PDF reports, and advanced reporting can be added next.
